# Bauvorlagen Stil 1

Je Design-Element eine Bauvorlage (Maße, Farben, SVG/CSS, Zustände, betroffene Dateien und Tests).
Zeichenflächen dazu in der Bauteil-Bibliothek (Claude Design): https://claude.ai/artifact/Sh1JhJ3E4h97wTMLVNEkDs
Inhaltsverzeichnisse: `C.md` (Vollbild, HUD), `D.md` (Ringmenü, Start, Overlays), `E.md` (Handy). Code-Vorlagen für C in `code/`.

Entscheidungen (2026-11-27): Maßstab Variante B (keine Bedienfläche über einer Feldkachel, Kachel 48,5 px bei 1280x800); Startbildschirm bei jedem Laden (e2e mit Helfer `enterGame`); Handy hochkant füllt die Höhe, seitlich wischen.
