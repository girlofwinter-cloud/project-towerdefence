# Icons

SVG-Icons der Bedienung, wörtlich aus den Bauvorlagen `HUD-Leiste.md`, `HUD-Knoepfe.md`, `HUD-Faehigkeiten.md`. Mehrfarbig, Kontur immer `ink` (#2b1a10), helle Füllung `cream` (#fff3d2). Größe: HUD 36–40 px, Knopf 40 px, Fähigkeit 46 px. Im Spiel stehen sie inline im HTML (`aria-hidden="true"`), der Text daneben liegt in `.sr`.
